# research/
Web research notes: `notes/<topic>.md`. Each starts with a header:

    status: unverified | confirmed | refuted
    source: <url>   fetched: YYYY-MM-DD
    tested-by: <result id or brain entry once an outcome exists>

Everything fetched starts `unverified`. It becomes `confirmed` or `refuted` only after a practice outcome, recorded in wins.md/failed.md. Never turn an unverified note into a rule or skill. The Coworld's own how-to is `<coworld folder>/documents/howto.md`.
