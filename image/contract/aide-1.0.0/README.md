# AIDE 1.0.0 Contract Schema

`asyncapi.json` is the published AIDE 1.0.0 AsyncAPI 3.0.0 contract schema, vendored here so
`core/tests/test_aide_backend.py` can validate every AIDE request, result, error, and notification
frame without depending on an external checkout.
